# 四方博弈图

麻将桌式的「政策 / 我 / 散户 / 主力」四方博弈可视化，同心方框随时间（T1–T6）向外扩展，每层框内侧显示该阶段局况。

## 在线访问

- GitHub Pages：推送后在这里 → `https://<用户名>.github.io/<仓库名>/`
- 另一份已发布的分享链接：https://workbuddy.link/p/As2eGGxx5H8eGueIqhUjwf

## 使用

1. 直接打开页面即可，无需联网、无外部依赖
2. 点右上角「编辑」可改：标的池、各阶段局况、四方动作
3. 编辑内容保存在浏览器 localStorage，换电脑不同步——重要改动建议回本地文件改
4. 拖动底部时间轴 T1–T6 查看每一局的四方动作

## 云同步（口令加密 + GitHub Gist）

无需注册任何服务：

1. 生成 GitHub **classic 令牌**，只勾 **`gist`** 一项（https://github.com/settings/tokens）
2. 页面点「☁ 云同步」→ 填令牌 + 设一个口令 → **保存到云端**
3. 换设备：填同一个令牌 + 同一个口令 → **从云端读取**

- 数据在本机用 PBKDF2 + AES-GCM 加密后才上传，存进**私密 Gist**，GitHub 也看不到明文
- 令牌只保存在本机浏览器，不写进页面、不随分享链接传播
- **口令遗忘无法恢复**，请与导出的 `.enc.json` 备份一起保存
- 不想用云端时，可用「导出加密文件 / 导入文件」离线迁移

## 功能要点

- 四方角色固定在开局座位（麻将桌东南西北风位），不随方框外扩移动
- 六层同心方框代表六个阶段，随时间轴向外扩展
- 每层框内侧显示该阶段局况摘要
- 底部可新增/切换不同标的，每个标的独立保存自己的剧本
